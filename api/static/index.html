A DISTRIBUTED DOCUMENT-COMPARISON PROJECT

Find documents that contain similar text.

Comparing a large collection one pair at a time can be slow. SimilarDocs splits the work across worker services, then ranks document pairs by textual overlap for a person to review.

Where this can help: educators reviewing submissions, editors checking drafts, or teams finding repeated content in a document archive.

How it works

  1. Add documentsGenerate a safe sample dataset or upload text files.
  2. Compare in parallelRabbitMQ distributes comparison tasks to workers.
  3. Review likely matchesInspect ranked pairs, scores, and highlighted shared text.

A score signals text overlap; it does not prove plagiarism. Human review is essential.
